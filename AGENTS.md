# Commits

Use [conventional commits](https://www.conventionalcommits.org/) for all commit messages. Format: `type(scope): description` — e.g. `feat(auth): add login rate limiting`, `fix(ui): correct button alignment`. Common types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`.
